# Professionalethicalslinks

This repository hosts the **Professional Hub** static landing page available at [`professionalhub.html`](professionalhub.html).

## Viewing the page

1. Click the `professionalhub.html` file in the repository to preview its source on GitHub.
2. To view it rendered as a webpage, download the file or open the raw view and save it locally.
3. Open the saved file in any modern browser to explore the Professional Hub landing page.
